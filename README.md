# 浅川ベアーズ 配車ボード

ホワイトボードとマグネットでやっていた配車を、スマホで回答・自動割り振り・手直し・LINE共有できるようにしたWebアプリです。

- アプリのURL：https://asakawa-bears.github.io/haisha/
- 使い方ガイド：https://claude.ai/artifact/623aQXJsGE7wSaz3cCArby

## しくみ

| 部分 | 使っているもの | 費用 |
|---|---|---|
| 画面（このリポジトリの `index.html`） | GitHub Pages | 無料 |
| データの保存・同期 | Firebase（Cloud Firestore） | 無料プラン（Spark） |
| ログイン | Firebase 匿名認証（利用者は何も入力しない） | 無料 |

- アプリは `index.html` 1ファイルだけです。`main` ブランチに入れると数分で公開URLに反映されます。
- 誰かが変更すると、開いている全員の画面にすぐ反映されます。
- 電波が弱いときも操作でき、つながったときに自動で保存されます。

## 保存しているデータ

名簿（家庭名・子どもの名前と学年・指導者名）、イベント、回答、配車ボード、要対応、変更履歴だけです。住所・電話番号・メールアドレスは保存しません。

- 30日より前のイベントはアプリに出なくなります（データは残りますが読み込まないので、無料枠の節約になります）。
- 変更履歴は新しい40件を表示し、「この前に戻す」で戻せます。

## データベースのルール（最初に1回だけ）

`firestore.rules` の中身を、Firebase コンソール →「Firestore Database」→「ルール」に貼り付けて「公開」します。

ルールでやっていること：
- アプリから（匿名ログイン済みで）来た書き込みだけ受け付ける
- 名簿・イベント・回答などの形と長さが正しいものだけ保存する
- 変更履歴は書き換え禁止。消せるのは1日より前のものだけ（いたずらで全部消されても、直近の変更は戻せる）
- それ以外の場所には読み書きさせない

アプリに「保存できませんでした（Firebaseのルール設定を確認してね）」と出たら、ルールが貼れていないか古いです。

## 無料枠の目安

Firestore 無料プラン：読み取り 1日5万回、書き込み 1日2万回、保存 1GB。
アプリを1回開くと、名簿などの件数（チーム全体で120件ほど）を読み取ります。40家庭が1日に数回ずつ開いても枠内です。
超えた場合はその日の残り時間だけ読み書きが止まり、翌日（日本時間の夕方ごろ）に戻ります。課金はされません。

## 合言葉なし・ログインなしについて

チームで決めたとおり、URLを知っている人は誰でも見て編集できます。
- URLは検索エンジンに載らない設定（noindex）にしています。
- 間違って消しても、名簿の画面の「変更履歴」から戻せます。
- 気になるときは、Firebase の API キーに「HTTPリファラー：asakawa-bears.github.io/*」の制限をかけると、ほかのサイトから使われにくくなります（Google Cloud コンソール →「APIとサービス」→「認証情報」）。

## よくあるとき

| こんなとき | どうする |
|---|---|
| 画面が「読み込み中」のまま | 電波を確認。Firebase 側で匿名ログインが「有効」になっているか確認 |
| 「保存できませんでした（ルール…）」 | 上の「データベースのルール」を貼り直す |
| データを全部消して最初からやり直したい | Firebase コンソールの Firestore で各コレクションを削除 |
| 古いデータ（30日より前のイベント）を消したい | Firebase コンソールの Firestore →「events」から削除（任意） |

## ファイル

- `index.html` … アプリ本体（画面・自動割り振り・同期のすべて）
- `firestore.rules` … データベースのルール（Firebase コンソールに貼るもの）
- `icon-180.png` … ホーム画面に追加したときのアイコン
- `.nojekyll` … GitHub Pages にそのまま配信させるための空ファイル
